# R code and documentation for "Neurotoxicity of organophosphate flame retardant: Integrating established molecular mechanistic pathways with network toxicology approaches"
## Overview
This repository contains the R code and documentation supporting the network toxicology analysis in the manuscript titled "Neurotoxicity of organophosphate flame retardant: Integrating established molecular mechanistic pathways with network toxicology approaches", submitted to *Environmental Toxicology and Pharmacology*.
The manuscript integrates a literature-based mechanistic review with network toxicology analysis of six representative organophosphate flame retardants (OPFRs): TDCPP, TPHP, TCP, BDP, DOPO, and HEDP. The R code in this repository performs GO functional annotation and KEGG pathway enrichment analysis on the intersection genes between OPFR-predicted targets and central nervous system (CNS) injury-related genes.
## Repository contents
- `GO_KEGG_analysis.R` — Main R script. Performs gene symbol cleaning, SYMBOL-to-ENTREZID conversion, GO enrichment (BP/CC/MF), and KEGG pathway enrichment, and exports result tables and bar/dot plots.
- `README.md` — This documentation file.
- `toxicant_disease_intersect_genes.csv`
Outputs generated by the script are written to two subfolders created automatically:
- `GO_analysis/` — GO enrichment result table (`GO_enrichment_results.txt`), `GO_barplot.pdf`, `GO_dotplot.pdf`
- `KEGG_analysis/` — KEGG enrichment result table (`KEGG_enrichment_results.txt`), `KEGG_barplot.pdf`, `KEGG_dotplot.pdf`
## Data sources
The intersection gene sets analyzed here were derived as described in Section 3.1 of the manuscript:
- **Compound target genes** for TDCPP, TPHP, TCP, BDP, DOPO, and HEDP were collected from ChEMBL, SwissTargetPrediction, and STITCH.
- **CNS injury-related disease genes** were screened from GeneCards.
- **Intersection analysis** between the two gene sets was performed on the MicroBioinformatics online platform (https://www.bioinformatics.com.cn/).
The resulting gene datasets have been deposited in the NIH Sequence Read Archive (SRA) under accession number **[https://doi.org/10.5281/zenodo.24362071]**, available at: **[https://zenodo.org/]**. The deposited file contains the intersection gene symbols used as the starting point for the R analysis (a table with a column named `gene`).
To reproduce the analysis, download the intersection gene file from the Zenodo and place it in the working directory as `toxicant_disease_intersect_genes.csv`.
## Requirements
- R version: **[R 4.5.2]**
- R packages:
  - `clusterProfiler`
  - `enrichplot`
  - `ggplot2`
  - `GOplot`
  - `BiocManager`
- Species annotation databases:
  - `org.Hs.eg.db` (human)
  - `org.Mm.eg.db` (mouse)
  - `org.Rn.eg.db` (rat)
The script automatically checks for missing packages and installs them via `BiocManager::install()` if they are not already present.
## How to run
1. Open `GO_KEGG_analysis.R` in R or RStudio.
2. Set the working directory to the folder containing the script and the input CSV file. **Note:** the script currently contains a hard-coded working directory (`setwd("D:/Network_Toxicology/GO_KEGG_analysis")`). Before running, replace this line with the path to your local folder, or delete it and set the working directory via `setwd()` / RStudio's session menu.
3. Confirm the species setting. The script defaults to `species <- "mouse"`. Valid options are `"human"`, `"mouse"`, and `"rat"`, which map to `org.Hs.eg.db`/`hsa`, `org.Mm.eg.db`/`mmu`, and `org.Rn.eg.db`/`rno`, respectively. **Note:** the species should match the organism used to generate the target and intersection gene sets in the manuscript; change this line only if the analysis is to be repeated in another species.
4. Confirm the input file name (`input_file <- "toxicant_disease_intersect_genes.csv"`). The CSV must contain a column named `gene` with gene symbols. This file should be downloaded from the SRA entry listed above, unless a copy is included in this repository.
5. Run the script. GO and KEGG result tables and PDF figures will be saved into `GO_analysis/` and `KEGG_analysis/`.
If compound-specific analyses were run separately for the six OPFRs, repeat steps 3–5 for each compound-specific intersection gene file, using the corresponding input file name.
## Analysis parameters
- GO enrichment: `ont = "all"`, `pvalueCutoff = 0.05`, `qvalueCutoff = 0.05`, `readable = TRUE`
- KEGG enrichment: `keyType = "kegg"`, `pvalueCutoff = 0.05`, `qvalueCutoff = 0.05`, `pAdjustMethod = "fdr"`
- Plots: GO bar/dot plots show top 6 categories per ontology with `split = "ONTOLOGY"`; KEGG bar/dot plots show top 8 categories.
## Notes on reproducibility
- Gene symbols are cleaned by removing duplicates, NA values, leading/trailing whitespace, and empty strings before ID conversion.
- If no significantly enriched terms/pathways are returned, the script issues a warning suggesting relaxation of the cutoff (e.g., `pvalueCutoff = 0.1`).
- The PPI network construction (STRING + Cytoscape) and molecular docking described in the manuscript were performed with separate software and are not covered by this R script. The PPI network was built from the intersection genes via the STRING database and analyzed in Cytoscape; molecular docking examined binding between OPFRs and core gene-encoded proteins. **[ Cytoscape 3.9.1; PYMOL 2.4]**
